# C Day 74 - Find the Smallest Number

This C program accepts multiple numbers from the user and finds the smallest number using a `for` loop and an `if` statement.

## Example

Input numbers:
```text
12, 45, 23, 7, 30
```

Output:
```text
Smallest number = 7
```

## Concepts Used

- `for` loop
- `if` statement
- Comparison operator `<`
- Variables
- `scanf()` and `printf()`

## How It Works

The program stores the first input as the initial smallest number. It compares every following number with the current smallest value. If a smaller number is found, the program updates the `smallest` variable.
